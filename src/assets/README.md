# 丝绸之路数据可视化项目 - 资源目录

## 目录结构

```
assets/
├── data/                    # 静态数据文件
│   ├── cities.json         # 城市数据（19个丝绸之路沿线城市）
│   ├── dynasties.json      # 朝代数据（汉、唐、宋、元、明、清）
│   ├── events.json         # 历史事件数据（20个重要事件）
│   ├── trades.json         # 贸易数据（商品和贸易记录）
│   ├── sites.json          # 文化遗址数据（20个遗址及文物）
│   ├── routes.json         # 路线数据（陆上和海上丝绸之路）
│   └── displayPresets.json # 3D文物展示预设配置
├── images/                 # 图片资源
│   └── placeholder.jpg     # 占位图片（用于所有图片资源）
├── models/                 # 3D模型文件
│   └── artifacts/          # 文物3D模型（GLB/GLTF格式）
└── styles/                 # 全局样式文件（待创建）
    ├── variables.scss      # 样式变量
    ├── mixins.scss         # 样式混合
    └── transitions.scss    # 过渡动画
```

## 数据文件说明

### cities.json
包含19个丝绸之路沿线重要城市的详细信息：
- 基本信息：名称、经纬度、描述
- 历史时期：所属朝代
- 贸易商品：主要交易物品
- 文化交流：文化特征和影响
- 地理位置：地理环境描述
- 重要事件：相关历史事件
- 现代遗址：现存历史遗迹

### dynasties.json
包含6个主要朝代的信息：
- 汉朝（前206-220年）
- 唐朝（618-907年）
- 宋朝（960-1279年）
- 元朝（1271-1368年）
- 明朝（1368-1644年）
- 清朝（1644-1912年）

### events.json
包含20个重要历史事件：
- 张骞出使西域
- 玄奘西行取经
- 郑和下西洋
- 马可·波罗游历中国
- 等等...

### trades.json
包含贸易商品和贸易记录：
- 10种主要商品：丝绸、瓷器、茶叶、香料、黄金、白银等
- 贸易记录：包含时期、起点、终点、商品、数量、价值等信息

### sites.json
包含20个文化遗址及其文物：
- 莫高窟、兵马俑、大雁塔等著名遗址
- 每个遗址包含详细的历史背景和考古发现
- 每个遗址至少包含一件文物信息
- 文物包含type和displayConfig字段用于3D展示

### routes.json
包含2条主要贸易路线：
- 陆上丝绸之路：从西安到君士坦丁堡
- 海上丝绸之路：从杭州到亚历山大港

### displayPresets.json
3D文物展示预设配置：
- 8种基础预设：陶器、雕塑、织物、金属器、玉器、绘画、瓷器、通用
- 4种自定义预设：兵马俑、佛像、丝绸、青铜器
- 每个预设包含相机距离、角度、光照强度等参数

## 图片资源

所有图片资源统一使用 `/images/placeholder.jpg` 占位图。
后续可以替换为真实的历史图片。

## 3D模型

3D模型文件应放置在 `models/artifacts/` 目录下，格式为 GLB 或 GLTF。
当前使用占位路径，后续可以添加真实的Blender导出模型。

## 地球纹理

地球纹理贴图已存在于 `public/textures/` 目录：
- earth-day.jpg
- earth-texture.jpg
- earth.jpg

## 使用说明

1. 所有数据文件使用JSON格式，便于前端直接加载和解析
2. 数据基于历史事实创建，具有真实性和教育意义
3. 图片使用统一占位图，保持数据结构完整性
4. 3D模型路径已预留，可直接替换为真实模型
5. 展示预设配置可根据实际需要调整参数

## 数据来源

- 城市数据：基于已提供的mapData.json整合
- 历史事件：基于丝绸之路历史事实创建
- 贸易数据：基于历史贸易记录模拟
- 遗址数据：基于真实考古遗址信息创建
- 地球纹理：使用已提供的NASA公开纹理
