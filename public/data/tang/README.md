# Tang data README

Dataset: Tang Dynasty (618–907) Silk Road east-middle segment points and routes

Reference: see `../../../../REFERENCES.md` (对应仓库参考文献索引)

Literature DOI: `10.11922/csdata.2018.0015.zh`

Data DOI / Original data URL: `10.11922/sciencedb.587` / http://www.sciencedb.cn/dataSet/handle/587

License / Usage: 请遵循原始数据发布许可（参见数据服务系统页面或仓库 `DATA_LICENSES.md`）。

Contact / Data provider: 数据作者：徐雪强、张萍；数据通信作者：张萍（`zhangping029@126.com`）。

How to cite (建议，GB/T):

徐雪强, 张萍. 唐代丝绸之路东中段交通线路数据集（618–907 年）[J]. 中国科学数据(中英文网络版), 2018. DOI: `10.11922/csdata.2018.0015.zh`。

Notes / 数据说明：
- 时间范围：公元 618–907 年
- 地理范围：中国陕西省、甘肃省、青海省、宁夏回族自治区和新疆维吾尔自治区；蒙古国；中亚哈萨克斯坦。
- 数据量：约 7.45 MB
- 格式：Shapefile（`*.shp`, `*.shx`, `*.dbf`, `*.prj`, `*.sbn`, `*.sbx`, `*.xml` 等）
- 组成：数据集由 2 个 Shapefile 文件组成：交通点数据与交通线数据；文件集合包含几何、索引、属性表、空间参考与元数据文件。

使用提示：请确保下载并保留同名的 Shapefile 文件集合以便正确加载（*.shp 与其配套文件）。
