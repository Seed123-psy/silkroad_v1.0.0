	- 地理范围：北纬24°14′56"–47°37′27"，东经108°53′38"–28°58′26"（涉及中国、蒙古、吉尔吉斯斯坦、塔吉克斯坦、克什米尔地区、印度、巴基斯坦、阿富汗、乌兹别克斯坦、哈萨克斯坦、土库曼斯坦、伊朗、伊拉克、叙利亚、黎巴嫩、埃及、土耳其）
	- 格式：Shapefile (`.shp`,`.shx`,`.dbf`,`.prj`,`.sbn`,`.sbx`,`.cpg`)、Excel (`.xlsx`)、文档 (`.docx`) 等
	- 大小：约 6.35 MB
