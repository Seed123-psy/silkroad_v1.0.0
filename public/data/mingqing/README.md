# MingQing data README

Dataset: Ming–Qing Silk Road built-up area extents (cities along the Silk Road)

Reference: see `../../../../REFERENCES.md` (对应仓库参考文献索引)

Literature DOI: `10.11922/csdata.2018.0023.zh`

Data DOI / Original data URL: `10.11922/sciencedb.645` / http://www.sciencedb.cn/dataSet/handle/645

License / Usage: 请遵循原始数据发布许可（参见数据服务系统页面或仓库 `DATA_LICENSES.md`）。

Contact / Data provider: 数据作者：薛樵风、成一农、金晓斌；数据通信作者：成一农（`342791@qq.com`）。

How to cite (建议，GB/T):

薛樵风, 成一农, 金晓斌. 明清时期丝绸之路沿线城市建成区范围 GIS 数据集[J]. 中国科学数据(中英文网络版), 2018. DOI: `10.11922/csdata.2018.0023.zh`。

Notes / 数据说明：
- 时间范围：1368–1911
- 地理范围：中国境内古代丝绸之路沿线各省（区），包括陕西省、甘肃省、青海省、宁夏回族自治区和新疆维吾尔自治区。
- 数据量：约 146 KB
- 格式：ESRI Shapefile（单个 Shapefile）
- 组成：数据集由 1 个 Shapefile 文件组成；随同文件通常包括 `*.shp, *.shx, *.dbf, *.prj, *.sbn, *.sbx, *.xml`，其中 `*.xml` 保存元数据。

使用提示：Shapefile 文件请保持完整文件集合以确保几何与属性信息正确解析。
