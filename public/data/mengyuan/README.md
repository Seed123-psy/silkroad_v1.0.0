# MengYuan data README

Dataset: MengYuan (Mongol period) Silk Road itineraries (points and routes)

Reference: see `../../../../REFERENCES.md` (对应仓库参考文献索引)

Literature DOI: `10.11922/csdata.2018.0017.zh`

Data DOI / Original data URL: `10.11922/sciencedb.622` / http://www.sciencedb.cn/dataSet/handle/622

License / Usage: 请遵循原始数据发布许可（参见数据服务系统页面或仓库 `DATA_LICENSES.md`）。

Contact / Data provider: 数据作者：程军、张萍；数据通信作者：张萍（`zhangping029@126.com`）。

How to cite (建议，GB/T):

程军, 张萍. 蒙元时期丝绸之路旅行家行程 GIS 数据集[J]. 中国科学数据(中英文网络版), 2018. DOI: `10.11922/csdata.2018.0017.zh`。

Notes / 数据说明：
- 时间范围：1218–1353
- 地理范围：北纬54°58'51.13"–24°45'2.75"，东经27°8'38.07"–111°9'34.73"（涉及：中国、哈萨克斯坦、蒙古国、塔吉克斯坦、吉尔吉斯斯坦、乌兹别克斯坦、土库曼斯坦、阿富汗、伊朗、巴基斯坦、印度、俄罗斯、阿塞拜疆、亚美尼亚、格鲁吉亚、土耳其、伊拉克、叙利亚、黎巴嫩、巴勒斯坦、以色列、约旦、沙特阿拉伯、巴林、乌克兰、罗马尼亚、保加利亚、埃及）
- 数据量：约 17.8 MB
- 格式：ESRI Shapefile（点集与线路集）
- 组成：数据集由 20 个行程点数据与 20 个行程线路数据组成（分别为点和线的 Shapefile 文件）；同时包含元数据 XML 与空间参考文件。

- 使用提示：Shapefile 系列文件应保持同名并一并使用（*.shp/*.shx/*.dbf/*.prj/*.sbn/*.sbx/*.xml）。
